PRIMEIRA INSTALAÇÃO
Execute com duplo clique: Instalar EduTrack.cmd

O instalador localiza ou instala o Python 3.12 para o usuário atual, prepara o
ambiente virtual e configura o PostgreSQL portátil. Não é necessário executar
arquivos .ps1 diretamente nem editar caminhos.

PARA INICIAR QUANDO PRECISAR
Execute com duplo clique: Iniciar EduTrack.cmd
Depois, abra http://127.0.0.1:8000

PARA ENCERRAR
Pressione Ctrl+C na janela do servidor.
Execute com duplo clique: Encerrar EduTrack.cmd
